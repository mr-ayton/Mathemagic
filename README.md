# Mathemagic

A simple C++ project for exploring **mathematics, programming, and particle-based visual effects**.
The idea is to create a system where glowing particles behave according to mathematical formulas and together form visual representations of magical effects.

## Current version

**v0.1.0 — Initial working version**
The project currently includes:
* basic particle rendering;
* particle position control;
* X and Y position sliders;
* SFML rendering;
* CMake build system.
